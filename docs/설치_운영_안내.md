# 재물조사 웹앱 설치·운영 안내 (기관 담당자용)

이 안내서는 프로그램을 처음 설치하는 담당자를 위한 것입니다. 순서대로 따라 하면 됩니다.

## 1. 준비물

- 항상 켜 둘 수 있는 Windows 10/11 PC 1대 (서버 역할). 직원 휴대폰은 이 PC와 **같은 와이파이**에 있어야 합니다.
- 받은 설치 파일 **`inventory-count-버전-setup.exe`** (Python이 들어 있어 따로 설치할 것이 없습니다).
  설치 프로그램을 쓸 수 없는 PC라면 `inventory-count-버전-portable.zip` 을 씁니다(2-1 참고).
- 회계 프로그램에서 내려받은 **고정자산대장 엑셀(.xlsx)**.
- (선택) 기관 로고 파일(svg 또는 png).

## 2. 설치와 처음 설정

1. `setup.exe` 를 더블클릭합니다. 관리자 권한을 묻는 창이 뜨면 **예**를 누릅니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다(서명 인증서가 없는 프로그램이라 나오는 안내입니다).
2. 설치 마법사에서 **다음**을 누릅니다. 설치 폴더는 기본값(`C:\InventoryCount`)을 그대로 두세요.
   아래 세 가지는 켜 둔 채 진행하는 것을 권장합니다.
   - **바탕화면에 바로가기 만들기**
   - **Windows 방화벽 허용** — 같은 와이파이의 휴대폰이 접속할 수 있습니다(이 프로그램만, 개인·도메인 네트워크에서만).
   - **PC를 켜면 자동으로 서버 시작** — 로그인하지 않아도 켜지고, PC를 끌 때 안전하게 멈춥니다.
3. 마지막 화면에서 **[마침]** 을 누르면 잠시 뒤 브라우저에 **처음 설정** 화면이 열립니다.
   열리지 않으면 바탕화면의 **재물조사** 바로가기를 누르거나 `http://localhost:8200/setup` 을 엽니다.
4. 설정 화면에서 위에서부터 채웁니다.
   1. **기관 정보**: 기관명을 적고, 로고 파일을 고르거나 끌어다 놓습니다.
   2. **접근 코드**: 직원용 접근코드와 관리자 코드(각각 숫자 6자리 이상, 서로 다르게)를 정합니다. 규칙에 맞으면 체크 표시가 됩니다. **꼭 메모해 두세요.**
   3. **고정자산대장**: 우리 기관 대장을 올리면 바로 검사해서 자산 수와 위치 수를 보여 줍니다. 형식이 틀리면 무엇이 빠졌는지 알려 줍니다.
   4. **공간**: 대장의 자산위치가 목록으로 나옵니다. 각 공간 옆에 구역(1층·2층·별관 등)을 적습니다.
   5. **재물조사표 양식**: 기관 양식이 있으면 올리고, 없으면 기본 양식을 그대로 씁니다.
   6. **백업 폴더**: 외장 드라이브나 NAS 경로를 적습니다(예: `E:\InventoryBackup`).
5. **[저장하고 시작하기]** 를 누르면 서버가 새 설정으로 다시 켜지고, 직원 접속용 **QR 코드** 화면이 나옵니다.
   이 화면을 인쇄해 붙여 두면 직원은 휴대폰 카메라로 찍기만 하면 됩니다.

> 처음 설정 화면은 **서버 PC에서만** 열립니다. 다른 기기로 접속하면 "설정 중입니다" 안내만 보입니다.

시작 메뉴의 **재물조사** 폴더에 `재물조사 열기`·`기관 설정 · 백업`·`서버 시작(창으로)`·`서버 끄기`·`지금 백업하기`·`설치·운영 안내` 바로가기가 있습니다.

### 2-1. 설치 프로그램 없이 쓰기 (portable.zip)

1. zip 파일을 마우스 오른쪽 클릭 → **압축 풀기**로 `C:\` 아래 고정 위치에 풉니다.
2. 폴더 안의 **`start.bat`** 을 더블클릭하면 검은 창이 뜨고 처음 설정 화면이 열립니다. 이후 4·5번은 같습니다.
3. Windows 방화벽 창이 뜨면 **"개인 네트워크" 허용**을 누릅니다. 자동 시작은 5장의 수동 방법으로 등록합니다.

## 3. 나중에 설정 바꾸기

관리 화면(앱 아래쪽 [관리] → 관리자 코드) 맨 아래의 **[기관 설정 · 백업]** 에서 같은 화면을 다시 열 수 있습니다.

- 기관명·로고·코드·자산대장·공간·양식·백업 폴더를 바꿀 수 있습니다. 코드 칸을 비워 두면 지금 코드를 그대로 씁니다.
- 직원 접속 주소와 QR 코드도 이 화면 맨 위에 있습니다.
- **[지금 백업하기]**: 실사 결과와 사진을 백업 폴더에 바로 백업합니다.
- **[실사 결과 모두 지우기]**: 연습으로 저장한 결과를 지우고 실제 조사를 시작할 때 씁니다. 지우기 전에 자동으로 백업합니다.
- 대장에 있지만 공간 목록에 없는 위치의 자산은 홈 화면 **"기타"** 에 따로 모입니다.
- **실사를 시작한 뒤에는 고정자산대장을 되도록 바꾸지 마세요.** 대장을 올리면 이미 저장한 결과 중 코드가 사라지는 건수를 미리 알려 줍니다.

## 4. 직원이 접속하는 방법

- 설정 완료 화면이나 [기관 설정]의 QR 코드를 휴대폰 카메라로 찍습니다. 주소를 직접 입력해도 됩니다(예: `http://192.168.0.25:8200`).
- 조사자 이름과 접근코드를 입력합니다. 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다.

## 5. PC를 켜면 자동으로 시작하기

설치 프로그램에서 **PC를 켜면 자동으로 서버 시작**을 켰다면 이미 등록돼 있습니다. 끄거나 다시 켜려면 `setup.exe` 를 다시 실행해 체크를 바꿉니다.

portable.zip 으로 설치한 경우에만 아래처럼 직접 등록합니다.

1. 시작 메뉴에서 **PowerShell을 마우스 오른쪽 클릭 → 관리자 권한으로 실행**합니다.
2. 아래를 입력합니다(경로는 설치한 폴더로 바꾸세요).
   ```
   cd C:\재물조사\inventory-count-1.0.0-portable
   powershell -ExecutionPolicy Bypass -File .\scripts\install-autostart.ps1
   ```
3. 이제 PC를 켜면 로그인하지 않아도 서버가 켜지고, PC를 끌 때 서버를 안전하게 멈춘 뒤 백업을 시도합니다.
   해제하려면 `scripts\uninstall-autostart.ps1` 을 같은 방법으로 실행합니다.

## 6. 백업

- **`backup.bat`** 을 더블클릭하면 실사 결과와 사진을 백업합니다. 서버가 켜져 있어도 됩니다.
- `start.bat` 창에서 Ctrl+C로 서버를 끄면 자동으로 한 번 백업합니다. 그래도 조사 기간에는 하루 한 번 `backup.bat` 실행을 권장합니다.
- `.env` 에 `BACKUP_DIR` 을 적으면 그 폴더에, 없으면 프로그램 폴더 안 `backups` 에 저장합니다.
  **PC가 고장 나면 같은 디스크의 백업도 함께 잃을 수 있으니** 외장 드라이브·NAS를 권장합니다.
- 백업은 자동으로 지워지지 않습니다. 오래된 백업은 가끔 정리하세요.
- 복원: 서버를 끈 뒤 `data` 폴더를 백업 폴더 내용으로 바꾸고 다시 켭니다.

## 7. 업데이트와 제거

**설치 프로그램으로 설치한 경우:** 새 버전 `setup.exe` 를 실행하기만 하면 됩니다.
설치 프로그램이 먼저 서버를 끄고 지금 자료를 백업한 뒤 프로그램 파일만 바꿉니다.
`.env`(설정)·`data`(실사 결과·사진)·`backups`·`assets`(기관 엑셀)·`branding`(로고)은 그대로 둡니다.
데이터 구조가 바뀌는 업데이트라면 첫 실행 때 자동으로 변환됩니다.

**제거:** Windows 설정 → 앱 → **재물조사** → 제거. 서버를 끄고 자동 시작·방화벽 규칙·프로그램을 지운 뒤,
**웹앱 자료도 지울지** 묻습니다.

- **아니요(기본):** 실사 결과·사진, 설정(.env), 기관 엑셀, 로고, 프로그램 폴더 안의 백업을 남깁니다. 다시 설치하면 그대로 이어서 씁니다.
- **예:** 위 자료를 모두 지웁니다. 되돌릴 수 없으니 필요한 자료는 먼저 **[기관 설정 · 백업] → 백업 파일 내려받기**로 받아 두세요.
- 설정 화면에서 따로 정한 외장 드라이브·NAS 백업 폴더는 어느 쪽을 골라도 지우지 않습니다.

**portable.zip 으로 설치한 경우:** **새 폴더에 풀고 자료만 옮기는 방식**으로 업데이트합니다. 이전 폴더는 되돌릴 수 있도록 남겨 둡니다.

1. `scripts\server-stop.bat` 으로 서버를 끄고, `backup.bat` 으로 백업합니다.
2. 새 zip을 새 폴더에 풉니다. 예) `C:\재물조사\inventory-count-1.1.0`
3. 이전 폴더에서 새 폴더로 `.env`, `data` 폴더, `assets` 의 엑셀 3개, `branding` 의 로고, (있다면) `backups`·`cloudflared.exe` 를 **복사해 덮어씁니다.**
4. 새 폴더의 `start.bat` 을 실행해 확인합니다. 자동 시작을 쓰고 있었다면 5장 절차를 새 폴더에서 다시 실행합니다.
5. "데이터(DB) 버전이 프로그램보다 새롭습니다" 라는 메시지가 나오면 이전 버전 폴더로 실행한 것이니 새 폴더에서 실행하세요.

## 8. 외부(인터넷)에서 접속해야 할 때 (선택)

- `start-external.bat` 을 실행하면 Cloudflare를 통해 임시 HTTPS 주소(`*.trycloudflare.com`)가 만들어집니다.
- 고정 주소가 필요하면 Cloudflare 계정에서 터널을 만들고 토큰을 `.env` 의 `CLOUDFLARE_TUNNEL_TOKEN` 에 넣습니다.
  관리자 패스키(지문·Face ID)를 쓰려면 그 고정 주소를 `PASSKEY_RP_ID`·`PASSKEY_ORIGIN` 에도 적습니다.
- 외부에 공개하면 접근코드만 알면 누구나 들어올 수 있으므로 코드를 길게 정하고, 조사 기간이 끝나면 끄세요.

## 9. 자주 묻는 문제

| 증상 | 확인할 것 |
| --- | --- |
| 휴대폰에 "설정 중입니다"가 나온다 | 처음 설정이 끝나지 않았거나 자산대장을 읽지 못한 상태입니다. 서버 PC에서 `http://localhost:8200/setup` 을 열어 표시된 항목을 고칩니다 |
| 설정 저장 뒤 "서버가 다시 켜지지 않았습니다" | 검은 창(start.bat)을 닫았거나 직접 실행한 경우입니다. `start.bat` 을 다시 실행합니다 |
| "'자산코드' 머리글을 찾지 못했습니다" | 고정자산대장 첫 시트 위쪽에 `자산코드` 머리글이 있는지 확인 |
| 휴대폰에서 접속이 안 된다 | 같은 와이파이인지, 방화벽 허용을 눌렀는지, 주소 끝에 `:8200` 을 붙였는지 확인 |
| "10분 동안 잠겼습니다" | 코드를 10번 틀린 경우입니다. 10분 뒤 다시 시도하거나 서버를 다시 켜면 풀립니다 |
| 로고가 바뀌지 않는다 | 파일 이름이 `logo.png`/`logo.svg` 인지, `branding` 폴더에 있는지 확인 후 새로고침 |
| 홈 화면이 모두 "기타"에 있다 | 공간목록의 공간명과 대장의 자산위치 글자가 같은지 확인(띄어쓰기는 무시) |

## 10. 공개 체험판 운영 (배포하는 쪽용)

다른 기관이 설치 없이 둘러볼 수 있도록, 배포본을 체험 모드로 한 대의 PC에 띄우고 Cloudflare 터널로 공개합니다.
**운영 서버와 다른 폴더·포트·터널**을 씁니다. 예) 운영판 `8200`, 체험판 `D:\inventory_demo` · `8300`.

1. 체험판 패키지 `inventory-count-버전-demo.zip` 을 풀면 아래 설정(.env)과 Python·cloudflared가 이미 들어 있습니다. 직접 만들 때는 `.env` 를 다음처럼 둡니다(체험 코드는 로그인 화면에 그대로 공개됩니다).
   ```
   ORG_NAME=예시복지관 (체험판)
   ACCESS_CODE=123456
   ADMIN_CODE=654321
   DEMO_MODE=1
   V3_PORT=8300
   TASK_PREFIX=InventoryDemo
   FEEDBACK_URL=(의견 받을 설문 주소, 선택)
   ```
2. 체험 모드에서는 다음처럼 동작합니다.
   - 로그인 화면에 체험 코드가 보이고, 화면 위쪽에 "입력한 내용은 매일 새벽 4시에 지워집니다"라는 안내 띠가 나옵니다.
   - 서버를 켤 때와 매일 새벽 4시 이후에 실사 결과·이력을 지우고 예시 자료 상태로 돌아갑니다.
   - 촬영한 사진은 저장하지 않습니다. 서버 문자 인식(Vision)과 패스키는 꺼집니다.
3. 서버와 터널 켜기: **`start-external.bat`** 을 더블클릭하면 서버 창이 따로 뜨고, 이 창에 `https://…trycloudflare.com` 주소가 나옵니다. 창 없이 켜려면 `scripts\server-start-hidden.vbs` 와 `scripts\cloudflared-start-hidden.vbs` 를 더블클릭합니다(창 없이 실행).
4. **고정 주소 만들기**: Cloudflare 대시보드 → Zero Trust → Networks → Tunnels → Create a tunnel(Cloudflared)
   → 이름 `inventory-demo` → 표시되는 토큰을 체험판 `.env` 의 `CLOUDFLARE_TUNNEL_TOKEN` 에 넣습니다.
   Public Hostname 에 `demo.도메인` → Service `HTTP` · `localhost:8300` 을 추가한 뒤 터널을 껐다 켭니다.
   **운영 서버의 터널 토큰을 같이 쓰지 마세요.** 같은 터널에 연결돼 운영 주소 접속이 이 PC로 잘못 갈 수 있습니다.
   토큰이 없으면 임시 주소(`https://…trycloudflare.com`)로 열리며, 주소는 `data\cloudflared.log` 에 적히고 터널을 다시 켤 때마다 바뀝니다.
5. **자동 시작**: 체험판 폴더에서 관리자 PowerShell로 `scripts\install-autostart.ps1` 을 실행합니다.
   작업 이름이 `InventoryDemo-*` 로 만들어져 운영 서버 작업(`InventoryCountServer-*`)과 겹치지 않습니다.
6. **끄기**: 체험판 폴더의 `scripts\server-stop.bat`. 이 폴더의 포트(8300)와 터널만 끄고 운영 서버는 건드리지 않습니다.
   체험 기간이 끝나면 `scripts\uninstall-autostart.ps1` 로 자동 시작도 해제하세요.
