# 개발자 안내

코드를 고치거나 배포 패키지를 만드는 사람을 위한 안내입니다. 기관 담당자용 안내는 [설치_운영_안내.md](설치_운영_안내.md)에 있습니다.

## 구성

- 백엔드: FastAPI + Uvicorn + SQLite + openpyxl(엑셀 서식 보존 채우기). 포트 기본 8200.
- 화면: 빌드 단계 없는 바닐라 HTML/CSS/JS ES 모듈. 글꼴(Pretendard)과 브라우저 문자 인식(Tesseract.js)을 앱에 포함해 인터넷 없이도 동작합니다.
- 인증: 접근코드·관리자 코드(쿠키), 필요하면 관리자 패스키(WebAuthn, 고정 HTTPS 주소 필요).
- 문자 인식: 서버 Google Vision(키가 있을 때) → 없으면 브라우저 Tesseract.

```
app/          FastAPI 백엔드
  config.py     설정·경로(.env), 코드 규칙
  catalog.py    고정자산대장 읽기와 코드 색인
  locations.py  공간 목록(공간목록.xlsx 또는 자산위치 자동 구성)
  database.py   SQLite — 실사 결과·append-only 감사 이력·마이그레이션
  excel.py      재물조사표 출력(머리글 이름으로 열 찾기)
  setup.py      설정 화면 도우미(.env 쓰기, 엑셀 검사, 공간목록 쓰기)
  main.py       라우팅·인증·설정 모드·관리 API
assets/       고정자산대장.xlsx · 공간목록.xlsx · 재물조사표.xlsx (저장소에는 예시 가상 자료)
branding/     기관 로고(logo.svg/png) — 저장소에는 넣지 않음
static/       화면(index.html·setup.html·js·styles), 글꼴(fonts), 브라우저 OCR(vendor/tesseract)
installer/    Inno Setup 설치 스크립트
scripts/      런타임 준비·자동 시작·백업·배포 패키지 도구
tests/        자동 테스트
docs/         안내 문서와 README 화면 이미지
data/         survey.db · images/ (실행 중 생성, 저장소 제외)
```

## 개발 환경

Python 3.10 이상이면 됩니다.

```
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8200
python -m unittest discover -s tests
```

- `.env`가 없거나 코드가 비어 있으면 **설정 모드**로 켜집니다. 서버 PC에서 `http://localhost:8200/setup`이 열리고 저장하면 `.env`·`assets/`·`branding/`에 쓴 뒤 종료 코드 3으로 끝납니다. `start.bat`·`scripts/server-start.bat`는 종료 코드 3이면 다시 켭니다.
- **개발 폴더에서 설정 화면의 [저장]을 누르지 마세요.** 예시 엑셀(`assets/`)이 바뀌고, 배포 검사가 "예시 표시가 없다"며 패키지 생성을 멈춥니다. 시험은 복사본 폴더에서 합니다.
- 날짜·시각은 서버 시간대와 관계없이 `app/clock.py`의 KST(UTC+9) 기준입니다.
- DB 구조를 바꾸면 `app/config.py`의 `SCHEMA_VERSION`을 올리고 `app/database.py`의 `MIGRATIONS`에 변경 SQL을 넣습니다. DB가 프로그램보다 새 버전이면 서버가 시작을 거부합니다.
- 모든 저장·삭제는 `result_history`에 append-only 감사 이력으로 남깁니다. 이 동작을 깨지 마세요.

## 배포 패키지 만들기

버전은 `app/config.py`의 `APP_VERSION` 하나로 관리합니다.

| 명령 | 결과 | 용도 |
| --- | --- | --- |
| `python scripts/build_release.py` | `release/inventory-count-<버전>.zip` | 앱만(Python 설치된 PC용) |
| `... --portable` | `...-portable.zip` | Python·패키지 포함, 압축 풀고 `start.bat` |
| `... --installer` | `...-setup.exe` | 포터블을 설치 마법사로 감쌈(**기관 배포 1순위**) |
| `... --demo` | `...-demo.zip` | 포터블 + 체험판 설정 + cloudflared |

`build_release.py`는 정해진 파일만 담고 실데이터·비밀값(`.env`, `data/`, 런타임 등), 예시 표시(`SAMPLE-DUMMY`)가 없는 엑셀, `branding/`의 기관 로고, 원 개발 기관 흔적이 있으면 패키지를 만들지 않습니다.

**포터블·설치 프로그램에 필요한 준비물** (저장소에는 없음, `.gitignore` 대상)

1. `python/`: python.org 의 *Windows embeddable package (64-bit)* 3.12 를 풀고 `python312._pth`를 아래처럼 바꿉니다.
   ```
   python312.zip
   .
   ..\.runtime-py312
   ..
   import site
   ```
2. `.runtime-py312/`: `python -m pip install --target .runtime-py312 -r requirements.txt` (같은 3.12로 실행)
3. 체험판만: `cloudflared.exe`
4. 설치 프로그램만: Inno Setup 6. `ISCC.exe`는 `INNO_ISCC` 환경변수 → 상위 폴더의 `.tools/innosetup` → 기본 설치 경로 순으로 찾습니다.

설치 프로그램은 `C:\InventoryCount`에 설치하고(Program Files는 일반 사용자가 쓸 수 없음), 업데이트 때 `.env`·`data`·`backups`·`assets`·`branding`을 건드리지 않습니다. 코드 서명을 하지 않아 처음 실행 때 SmartScreen 경고가 뜹니다.

## 자료 규칙

**고정자산대장 읽기**

- 첫 시트 위쪽 10행 안에서 `자산코드` 머리글 행을 찾고, 머리글 이름으로 열을 읽습니다(열 순서 무관).
- 필수: `자산코드`·`자산명`·`현재수량`(또는 `장부수`). 선택: `자산분류`·`취득일자`·`자산상태`·`자산위치`·`운영부서`·`용도`. 금액·감가상각 열은 읽지 않습니다.
- 자산코드가 없는 `소계`·`합계` 행은 건너뜁니다. 같은 코드가 두 번 나오면 첫 행을 씁니다.
- 3마디(`08-01-002`)와 4마디(`03-05-012-0001`) 코드를 받습니다. 4마디는 앞 3마디가 같으면 같은 품목으로 묶어 한 번에 실사할 수 있습니다.

**재물조사표 출력**

- 위쪽 10행의 머리글 이름(`조사일자`·`자산코드`·`사용가능`·`폐품`·`활용`·`과부족`·`사유` 등)으로 열을 찾습니다.
- 조사일자: 실사 등록일(YYYYMMDD)을 실사한 행에만. 사용가능·폐품·활용: 세 열을 0으로 두고 실사한 상태 열에만 실사 수량. 과부족·사유: 실사 값.
- 채워진 양식이면 그 밖의 열은 고치지 않고, 빈 양식이면 자산대장 순서로 행을 만듭니다. 위치 변경은 출력하지 않습니다.

## 보안

- 접근코드·관리자 코드는 숫자 6자리 이상이고 서로 달라야 합니다. 10번 틀리면 그 접속 주소를 10분 잠급니다(Cloudflare 경유 시 원래 주소 기준).
- 처음 설정은 서버 PC(localhost)에서만 열립니다. Cloudflare 터널로 들어온 요청은 localhost로 보이므로 전달 헤더로 걸러 냅니다.
- 사내 와이파이 접속은 HTTP입니다. 외부 공개는 `start-external.bat`(HTTPS 터널)으로만 합니다.
- 자동 시작은 폴더에 `cloudflared.exe`가 있을 때만 외부 터널을 함께 켭니다.

## 디자인 시스템 (화면을 고칠 때 반드시)

색·타이포·컴포넌트는 모든 기관이 같고, 기관마다 바뀌는 것은 기관명과 로고뿐입니다.

1. **토큰만 씁니다.** 색·그라디언트·그림자 값은 `static/styles/tokens.css` 에만 적습니다. 다른 CSS·JS·HTML·Python에는 `#hex`·`rgb()` 대신 `var(--color-…)` 같은 시맨틱 토큰을 씁니다. 새 색이 필요하면 역할 이름의 토큰을 tokens.css에 먼저 추가하고 라이트·다크 값을 함께 정합니다(예외: `<meta name="theme-color">`). 글자 `--type-*`, 간격 `--space-*`, 모서리 `--radius-*`, 그림자 `--elevation-*`, 층 `--layer-*`, 크기 `--size-*`, 글꼴 `var(--font-sans)`. 외부 CDN은 쓰지 않습니다.
2. **색의 역할.** Primary 블루(`--color-primary`)는 CTA·링크·포커스·활성. Accent 오렌지(`--color-accent`)는 배경·선·장식 같은 제한적 포인트에만 쓰고 **글자색으로 쓰지 않습니다.** 보조 텍스트는 `--color-ink-secondary`·`--color-ink-muted`. 상태 색은 활용=블루, 사용가능=오렌지 계열, 폐품=그레이/위험 계열. QR은 `--color-qr-dark`·`--color-qr-light`.
3. **있는 컴포넌트를 씁니다.** `.primary-button` `.secondary-button` `.text-button` `.text-danger` `.card` `.notice` `.field-title` `.field-help` `.button-row` `.sr-only`, JS는 `ui.js`의 `icon()`·`toast()`·`busy()/idle()`·`choose()`·`prompt()`. 브라우저 `alert/confirm/prompt` 창은 쓰지 않습니다.
4. **버튼 모서리**는 `--radius-lg`/`--radius-md`(알약 금지, 원형 아이콘 버튼·칩·배지만 예외). **입력 포커스**는 `border-color: var(--color-primary)` + `box-shadow: var(--ring-focus)` + `outline: none`. 토스트는 모달 위(`--layer-toast`).
5. **새 페이지**는 tokens.css를 먼저 불러오고 그리기 전에 `inventory-theme` 다크 모드 초기화 스크립트를 넣고, `#app`·`#toast`·`#loading`·`#loadingText`를 둡니다.
6. **접근성.** 모든 조작은 키보드로 가능해야 합니다. 파일 input은 `hidden` 대신 `.sr-only` + label 버튼, 아이콘만 있는 요소에는 aria 라벨.

`python -m unittest tests.test_design_system`이 이 규칙을 자동으로 검사합니다. 예외는 테스트의 `ALLOWED_*`에 이유 한 줄과 함께만 추가하고 테스트를 느슨하게 고쳐 통과시키지 않습니다. 화면을 바꾸면 라이트·다크 두 테마와 휴대폰 너비(약 390px)에서 직접 열어 확인합니다.
