# 기관 로고 넣는 곳

화면 왼쪽 위와 로그인 화면, 브라우저 탭 아이콘에 쓰이는 로고입니다.

1. 기관 로고 파일 이름을 `logo.svg` 또는 `logo.png`(`logo.webp`, `logo.jpg`도 가능)로 바꿉니다.
2. 이 폴더(`branding\`)에 넣습니다.
3. 휴대폰·PC 브라우저에서 새로고침합니다. 서버를 다시 켤 필요는 없습니다.

- 가로가 긴 로고도 쓸 수 있습니다. 화면에서는 높이 23px, 너비 최대 120px로 줄여서 보여 줍니다.
- 정사각형 심볼(로고의 그림 부분)이 휴대폰 화면에서 가장 잘 보입니다.
- 파일이 없으면 기본 재물조사 아이콘이 표시됩니다.
- 업데이트할 때 이 폴더는 그대로 두세요.
